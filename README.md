# Al Rayes Digital Ecosystem

The ultimate digital backbone for Al Rayes Laundry—Doha's 46-year laundry pioneer.

## Project Structure
- `apps/frontend`: Vue 3 + TypeScript frontend for all department portals.
- `apps/portal-gateway`: FastAPI microkernel backend (Internal Operations Hub).
- `packages/core`: Shared core logic and interfaces.

## Features
- **Multi-Portal Architecture**: 23+ distinct department portals.
- **Dynamic Theming**: Spec-compliant visual identities for every department.
- **RBAC**: Robust Role-Based Access Control.
- **LMS Integration**: 13-stage garment tracking lifecycle.
- **100% FOSS**: Built entirely with Free and Open Source Software.
